# 학교회계 질의회신

대학 회계·계약·사업비 집행 질의와 검토 의견을 모은 정적 사이트입니다 (GitHub Pages).

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 (목록·검색·태그 필터·상세, `#QA-2026-001` 형식 링크) |
| `data/qa.js` | 질의회신 데이터. 새 질의는 배열 맨 앞에 추가 |
| `_private/매핑.json` | 질의 ID ↔ 실제 학교·Gmail 스레드. **GitHub에 올라가지 않음** |

## 공개 원칙 (익명화)

공개 사이트이므로 `data/qa.js` 에는 다음을 넣지 않습니다.

- 학교명, 법인명, 부서명, 담당자 이름·연락처·메일 주소
- 학교를 특정할 수 있는 고유 사업명·시스템명·건물명·정확한 금액 (예: "약 2억 원 규모"처럼 범위로)
- 메일 원문

학교 구분은 `org` 에 "사립 4년제 대학 · 혁신지원사업"처럼 유형으로만 적습니다. 실제 학교는 `_private/매핑.json` 에 적습니다.

## 데이터 항목

`id`(QA-연도-번호) · `date` · `title` · `org` · `tags`(회계처리/계약/세무/사업비 집행 등) · `status`(회신 전/회신 완료)
· `conclusion` · `questions` · `sections`[{title, items}] · `checks` · `reply`

## 로컬에서 보기

`index.html` 을 더블클릭하면 브라우저에서 열립니다.
